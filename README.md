# Практическая работа: Подсчет количества цифр в числе

## 1. Таблица ручной трассировки

### А) При n = 472
| Итерация | n (до шага) | Действие / состояние | Количество (count) | Условие цикла (n > 0) |
| :---: | :---: | :--- | :---: | :---: |
| **Инициализация** | 472 | `count = 0` | 0 | — |
| **1** | 472 | 472 / 10 = 47, `count = 1` | 1 | Истинно |
| **2** | 47 | 47 / 10 = 4, `count = 2` | 2 | Истинно |
| **3** | 4 | 4 / 10 = 0, `count = 3` | 3 | Истинно |
| **Конец** | 0 | Цикл завершен | 3 | Ложь (выход) |

### Б) При n = 0
Для числа 0 используется отдельное условие (`n == 0`), так как цикл деления для нуля не выполняется. Присваивается `count = 1`.
