# Трассировка и анализ алгоритмов с массивами

Исходный массив: `a = {4, 1, 7, 3, 9}`, размер `n = 5`.

---

## 1. Циклический сдвиг влево на одну позицию
Сохраняем `buf = a[0] = 4`. Цикл смещает элементы влево: `a[i] = a[i+1]`, а в конце `a[n-1] = buf`.

| Шаг | `i` | Состояние массива после шага | Описание действия |
| :--- | :---: | :--- | :--- |
| Начало | - | `{4, 1, 7, 3, 9}` | `buf = 4` |
| 1 | 0 | `{1, 1, 7, 3, 9}` | `a[0] = a[1]` (значение 1) |
| 2 | 1 | `{1, 7, 7, 3, 9}` | `a[1] = a[2]` (значение 7) |
| 3 | 2 | `{1, 7, 3, 3, 9}` | `a[2] = a[3]` (значение 3) |
| 4 | 3 | `{1, 7, 3, 9, 9}` | `a[3] = a[4]` (значение 9) |
| Финал | - | `{1, 7, 3, 9, 4}` | `a[4] = buf` (запись 4 в конец) |

---

## 2. Разворот массива на месте (`swap(a[i], a[n - 1 - i])`)

Трассировка для исходного массива `a = {4, 1, 7, 3, 9}`:
* **i = 0:** меняем местами `a[0]` (4) и `a[4]` (9). Массив: `{9, 1, 7, 3, 4}`
* **i = 1:** меняем местами `a[1]` (1) и `a[3]` (3). Массив: `{9, 3, 7, 1, 4}`
* **i = 2:** условие цикла `i < n / 2` (`2 < 2` в целых числах) ложно, цикл завершается.

### Вопросы:
1. **Сколько обменов выполнено?** 
   Выполнено **2** обмена (для `i = 0` и `i = 1`).
2. **Почему цикл идёт только до `n / 2`?** 
   Потому что если продолжить до конца массива (`n - 1`), элементы поменяются местами во второй половине зеркально и вернутся в исходное состояние. Доходя ровно до середины (`n / 2`), мы успеваем переставить каждую пару элементов ровно один раз.

## 3. Ошибка в алгоритме поиска минимума (`min = 0`)

Если переменная `min` изначально инициализирована числом `0` (как значение, а не индекс), алгоритм будет работать некорректно.

* **Пример массива, на котором алгоритм ошибается:** 
  `a = {5, 2, 8}`
* **В чем ошибка:** 
  Алгоритм сравнивает элементы массива с начальным значением `min = 0`. Поскольку все элементы массива больше нуля (`5 > 0`, `2 > 0`, `8 > 0`), условие поиска меньшего элемента никогда не выполнится, и программа вернет `0` вместо реального минимума `2`. (Кроме того, если в массиве есть отрицательные числа, `min = 0` тоже запутает логику).

### Исправление:
Начальное значение нужно инициализировать **первым элементом массива** (или первым индексом):
```cpp
int min = a[0]; // или int min_index = 0;
for (int i = 1; i < n; i++) {
    if (a[i] < min) {
        min = a[i];
    }
}
