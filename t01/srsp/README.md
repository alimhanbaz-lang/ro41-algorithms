# Практическая работа: Перевод секунд в часы, минуты и секунды

## Описание
Программа на языке C#, которая принимает на вход целое неотрицательное число секунд и переводит его в часы, минуты и секунды. Реализована защита от некорректного ввода (текст, отрицательные числа).

## Результаты тестирования

| Входные данные ($N$) | Ожидаемый / Полученный результат |
| :--- | :--- |
| **3725** | 1 ч. 2 мин. 5 сек. |
| **59** | 0 ч. 0 мин. 59 сек. |
| **86399** | 23 ч. 59 мин. 59 сек. |
| **0** | 0 ч. 0 мин. 0 сек. |
| *abc* (некорректный ввод) | Ошибка: введено некорректное значение. Требуется целое неотрицательное число. |
| *-10* (отрицательное число) | Ошибка: введено некорректное значение. Требуется целое неотрицательное число. |
