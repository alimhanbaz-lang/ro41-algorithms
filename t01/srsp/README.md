# СРСП 1: Перевод секунд в часы, минуты и секунды

## Описание задачи
Программа принимает на вход целое неотрицательное число секунд и переводит его в привычный формат времени: часы, минуты и секунды. Реализована защита от некорректного ввода (текст, отрицательные числа).

## Результаты тестирования

| Входное значение (секунды) | Ожидаемый / Полученный результат |
| :--- | :--- |
| **3725** | 1 ч. 2 мин. 5 сек. |
| **59** | 0 ч. 0 мин. 59 сек. |
| **86399** | 23 ч. 59 мин. 59 сек. |
| **0** | 0 ч. 0 мин. 0 сек. |
| **abc** *(некорректный ввод)* | Ошибка: введено не целое число. |
| **-15** *(отрицательное число)* | Ошибка: число секунд не может быть отрицательным. |
