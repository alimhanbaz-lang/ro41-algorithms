## 2. Понятность
1. **Исходная формулировка с нарушением:** Студент-первокурсник, сделай рефакторинг легаси-кода на C++ с использованием паттерна Singleton.

3. **Исправленная формулировка без нарушения:** 
   - Откройте файл с кодом программы в среде разработки.
   - Найдите повторяющиеся участки кода, выделенные маркером жёлтого цвета.
   - Замените их вызовом готовой функции calculateTotal(), описанной в методичке на странице 15.
