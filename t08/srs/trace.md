## Задание 1. Trim() и Split(';')
Исходная строка: `s = "  Ахметов Ерлан;85 "`

1. **`s.Trim()`**: Удаляет пробелы в начале и в конце строки.
   - Результат: `"Ахметов Ерлан;85"`
2. **`s.Split(';')`**: Разделяет строку на массив подстрок по разделителю `;`.
   - **Элемент массива [0]:** `"Ахметов Ерлан"` (длина: 13 символов)
   - **Элемент массива [1]:** `"85"` (длина: 2 символа)

## Задание 2. int.TryParse для строки `line = "Иванов Пётр;70;85;x"`

| Индекс | Часть строки | Результат TryParse | Значение `out` |
| :--- | :--- | :--- | :--- |
| 0 | `"Иванов Пётр"` | `false` | `0` |
| 1 | `"70"` | `true` | `70` |
| 2 | `"85"` | `true` | `85` |
| 3 | `"x"` | `false` | `0` |

**Что вернет TryParseScores и почему?**
Функция `TryParseScores` вернет `false` (или сгенерирует ошибку/прекратит выполнение, если не предусмотрена обработка), потому что метод `int.TryParse` возвращает `false`, если строка не может быть корректно преобрадована в число (как в случае с ФИО `"Иванов Пётр"` и буквой `"x"`).

## Задание 3. Создание объектов (string vs StringBuilder)

### Строка (`string`)
В C# строки (`string`) **неизменяемы** (immutable). Каждая операция конкатенации (`+=`) создаёт новый объект в памяти.
- Создаётся объектов: **5 штук** (пустая строка `""` и 4 новые строки на каждой итерации: `"0"`, `"01"`, `"012"`, `"0123"`).

### StringBuilder (`sb.Append`)
Класс `StringBuilder` является **изменяемым** (mutable) и работает с внутренним буфером.
- Создаётся объектов: **1 объект** `StringBuilder` (его внутренний буфер может увеличивать размер при необходимости, но сам объект остаётся тем же).

| Шаг цикла (`i`) | `s += i` (`string`) | `sb.Append(i)` (`StringBuilder`) |
| :--- | :--- | :--- |
| Старт | создана строка `""` (объект 1) | создан `StringBuilder` (объект 1) |
| `i = 0` | создана строка `"0"` (объект 2) | добавлен `"0"` в тот же буфер |
| `i = 1` | создана строка `"01"` (объект 3) | добавлен `"1"` в тот же буфер |
| `i = 2` | создана строка `"012"` (объект 4) | добавлен `"2"` в тот же буфер |
| `i = 3` | создана строка `"0123"` (объект 5) | добавлен `"3"` в тот же буфер |

## Задание 4. Метод ToUpеr() без присваивания

Строки в C# неизменяемы (`immutable`). Когда вызывается метод `s.ToUpper()`, он не изменяет исходную строку `s` в памяти, а **создаёт и возвращает новую строку** в верхнем регистре. 

Так как результат никуда не записывался (нет присваивания вида `s = s.ToUpper();`), ссылка на переменную `s` продолжает указывать на старую строку, которая осталась неизменной.
